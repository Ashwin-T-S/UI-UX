# Week 1, Day 2 — Learning summary

## What I read or watched
-  Read:
-  10 Usability Heuristics 
-  WCAG 2.2 accessibility guidelines
-  Refactoring UI — “Hierarchy Is Everything,” mainly the part about de-emphasizing elements.
## Three things I learned
1. I learned about the 10 usability heuristics and how they help make a website or app easier to use. I understood that small things like giving proper feedback, keeping things consistent, and helping users avoid mistakes can improve the overall experience.
2. I went through the WCAG 2.2 guidelines (level AA only),to understand how websites can be made usable for different people. I got the basic idea, but some of the standards were a bit confusing to me. I need to explore them more to understand how they work in real designs.
3. I learned that not every element on a screen needs to grab attention. Making less important things look simpler can help users focus on the main content. This can be done by adjusting colors, contrast, and font weight instead of making everything bold or prominent.
## One thing I did not understand
-  I couldn't fully understand some of the WCAG guidelines just by reading them. I think it will make more sense when I start designing something and check whether it follows those guidelines.
## Where I will use this
-  I will try to apply these learnings when working on the website redesign. I want to make the content easier to find, improve the visual hierarchy, and consider accessibility while designing the pages.
