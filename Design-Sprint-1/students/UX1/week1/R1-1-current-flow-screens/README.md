# R1.1 - Public Flow Screen Inventory

This folder contains the dated, public baseline record of the Kerala Public Service Commission portal captured during Sprint 1.

## File Descriptions

 `01-home.png`: The main home page of the Kerala Public Service Commission website viewed in English.
 `02-home-malayalam.png`: The exact same home page, but switched to Malayalam to check how the text and layout change.
 `03-notification.png`: The main page listing all active job notifications and announcements.
 `04-notification-samples-next.png`: A close-up screenshot of a specific job post (showing its category number) to see how     individual recruitments are displayed.
 `04-notification-samples.png`: An extra screenshot showing the next page or continued section of job listings.
 `04-notifications-categorie-1.png`: A screenshot showing a specific filtered job category view.
 `05-tips-to-applicants.png`: The official advice and warning page that tells candidates how to fill out forms and what mistakes to avoid.
 `06-otr-instructions.png`: The step-by-step guide page explaining how "One-Time Registration" (OTR) works.
 `07-confirmation-procedures.png`: The page explaining the mandatory rules for confirming exams before taking them.
 `08-thulasi-portal.png`: The public landing page of the secure login portal (you only looked at it, never logged in!).
 `09-new-registration-pdf.png`: The first page of the official downloadable PDF manual for new registrations.
 `10-confirmation-pdf.png`: The first page of the official downloadable PDF manual for exam confirmations.
 `gaps.md`: Documentation of unreachable screens and workflow boundaries.
