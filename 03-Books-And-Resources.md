# 03 - Books And Resources

Everything the program uses, when it is used, what it costs, and what to get first.

The program now runs 27 weeks: week0, weeks 1-24, week12b and week20b. Cohort codes are UX1 to UX10. Setup steps are in `04-Tools-Setup.md`. New docs 10, 11 and 12 cover GitHub, code corners and the extra labs.

**The rule:** Use each resource when a task needs it; you do not need to read or watch everything.

**Prices and links drift.** Last checked 10 October 2026. Prices are rough and change often; verify before you buy. Items marked as fast-moving in `09-Modern-Practice-Map.md` move fast.

Figma Starter plan has one team, one folder, 3 files, 30-day version history, no libraries, no Dev Mode. Do not make three files per sprint. Make one Figma file per sprint named `SPRINT-N UX{n}`, with one page per week. `n` is your cohort code, UX1 to UX10. Use Penpot when the 3-file limit blocks you. If the admin confirms an Education plan, libraries may be available, but do not assume it. Without libraries, share via a view-only Figma or Penpot link and exported tokens. The shared system lives in tokens (markdown or JSON) in `system/`.

## 8. AI tools

Allowed. Disclosed. Never the decision maker. The labs in `07-AI-In-Design.md` teach the practice; this table is the policy. Use free tiers only. For every tool below, check the free limit before use.

| Tool | Useful for | Never for |
|---|---|---|
| Claude, ChatGPT, Gemini (free tiers; check the free limit before use) | Generating options to react against, microcopy variants, reading unfamiliar code, summarising transcripts you have already read yourself | Making the decision, or inventing a research finding |
| Google Stitch (free tier; check the free limit before use) | First-pass UI ideas to react against | Deliverables |
| Figma AI features, Figma Make (free credits; check the free limit before use) | Renaming layers, first-pass content fill, searching across files, a throwaway prototype to compare against your spec | Layout decisions, or a deliverable |
| Cursor free, GitHub Copilot free (check the free limit before use) | Reading a component, small token or Storybook edits | Shipping code you cannot explain |
| v0, Lovable, Bolt, Uizard (free tiers; check the free limit before use) | Throwaway scaffolds to react against | Deliverables |
| Whisper-class transcription (check the free limit before use) | Interview transcripts, with the participant's consent covering it | Synthesis. That is your job. |
| AI-moderated interviews (check the free limit before use) | Nothing yet. Treat as unvalidated. | Replacing participants |

**The rule.** Anything an AI touched carries a one-line footer: what you used, and how you verified the output. You also log every use in `ai-log.md`.

> *AI note: used Claude to generate 8 alternative error messages. Selected 3, rewrote 2, tested all with one participant.*

AI-assisted work must include the required footer and ai-log.md entry. The oral defense is the equaliser. Nobody can outsource answering "why did you choose this".

**Participant data.** Use P1 and P2, never real names, faces, phone numbers or IDs. Never paste participant data into a tool whose data policy you have not read, and never where the consent form did not cover it.

## 9. Books you do not need

Asked often enough to answer directly.

- **Atomic Design** (Brad Frost): read it as history if you like. Do not build from it.
- **Hooked** (Eyal): read it with Indistractable or not at all.
- **Any "UX laws" listicle book**: Laws of UX, free, is better and states its own limits.
- **Anything promising a UX job in 30 days**: no.
